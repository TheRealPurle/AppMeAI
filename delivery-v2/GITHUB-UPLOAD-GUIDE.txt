Upload to the existing AppMeUp GitHub repository
================================================

Copy the two top-level folders from the ZIP into the repository:

  .github/workflows/appmeai-build-catalogue.yml
  catalogue-builder/*

The folders must keep these exact paths. Do not replace the repository's
existing root package.json and do not delete the existing refresh workflow.

After committing the files:

1. Open GitHub > Actions > AppMeAI build curated catalogue.
2. Choose Run workflow.
3. Use stores: apple,google
4. Use query_start: 0
5. Use query_limit: 5
6. Leave import_after_collect unchecked.
7. Download the appmeai-curated-catalogue artifact when the run finishes.

This first run is deliberately a non-importing quality test.
