# Saved official-listing metadata

The Huawei and Xiaomi JSON files preserve the full descriptions from the user-supplied v10 workflow exports (39 Huawei and 128 Xiaomi records), plus 12 Huawei and 2 Xiaomi records fetched from individual official store listings during v11 validation.

The collector reclassifies these records using current v11 evidence rules before importing them. The saved metadata is historical evidence, not a fresh availability check. Fresh collection can replace matching store IDs. No app identifiers or availability are invented to fill a category.

The snapshot covers Huawei GB and Xiaomi ID. Official app links remain attached to each record. Missing categories still fail the coverage gate.
